# Changelog

## 0.5.0 — 2026-11-10

- Added an in-page toolbar for one-click 25% / 50% / 75% / 100% image resizing.
- Toolbar can collapse to a small current-percentage button.
- Saved scale and toolbar state in browser-local extension storage.
- Kept comments and surrounding navigation at their original page size.
- Chromium and Firefox source versions included.
- First public source package adds independent icon assets, README, MIT license and privacy summary; no changes to the underlying scaling logic.

Firefox browser-specific package has not been verified on a real Firefox installation. Store submission and signing are not yet complete.
