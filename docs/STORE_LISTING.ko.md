# Webtoon Reader Zoom — 스토어 소개글 초안 (한국어)

> **제출 전 검토용 문서예요.** Chrome 웹 스토어와 Firefox Add-ons에 아직 제출하거나 승인받지 않았어요. 실제 브라우저 테스트와 스크린샷을 확인한 뒤 최종 등록해 주세요.

## 확장 프로그램 이름 제안

Webtoon Reader Zoom — 웹툰 본문 크기 조절

## 짧은 설명

네이버 웹툰의 본문 이미지만 25~100%로 조절해요. 댓글과 메뉴는 원래 크기로 유지해요.

## 상세 설명

PC에서 네이버 웹툰을 읽을 때 이미지가 너무 크게 느껴지나요?

**Webtoon Reader Zoom**은 웹툰 회차의 **본문 이미지 크기만 조절**하는 가벼운 브라우저 확장 프로그램이에요. 전체 페이지를 축소하지 않아도 댓글과 메뉴는 원래 크기로 볼 수 있어요.

### 이렇게 사용할 수 있어요

- 본문 이미지를 **25~100%** 사이에서 조절해요. 기본값은 **50%**예요.
- 웹툰 화면 오른쪽에서 **25% · 50% · 75% · 100%** 버튼을 한 번만 눌러 크기를 바꿔요.
- 화면의 조절바를 접어 공간을 덜 차지하도록 할 수 있어요.
- 확장 프로그램 팝업에서 **5% 단위**로 더 세밀하게 조절할 수 있어요.
- 마지막으로 사용한 배율과 조절바 상태를 브라우저에 저장해요.

### 개인정보와 권한

선택한 배율과 조절바 상태만 브라우저의 로컬 확장 프로그램 저장소에 보관해요. 계정 정보, 웹툰 열람 기록, 댓글, 웹툰 콘텐츠를 개발자 서버에 전송하지 않아요. 광고나 추적 SDK도 사용하지 않아요.

이 확장 프로그램은 **네이버 웹툰 PC 회차 페이지**에서만 본문 이미지를 조절하도록 만들어졌어요. 웹사이트 구조가 바뀌면 일부 기능이 작동하지 않을 수 있어요.

**비공식 독립 프로젝트예요.** NAVER WEBTOON과 제휴·승인·후원 관계가 없어요. 작품 이미지나 원본 콘텐츠는 포함하지 않아요.

## 제출 전에 확인할 내용

- 스토어 이름과 확장 프로그램 매니페스트 이름을 확정해 주세요.
- 실제 Chrome·Firefox 설치와 회차 전환, 배율 조절, 댓글 크기 유지 동작을 검증해 주세요.
- 확장 프로그램이 적용된 **실제 화면**을 캡처해 스토어 규격에 맞춰 준비해 주세요. 웹툰 저작물의 표시와 사용 권한에 유의해 주세요.
- 설명과 개인정보 고지가 제출 시점의 코드와 일치하는지 다시 확인해 주세요.
- Chrome과 Firefox의 심사·게시 상태는 각각 별도로 확인해 주세요.
